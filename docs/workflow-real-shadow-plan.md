# 実タスクshadow計測の実行計画

ユーザーの2026-09-28追記を仕様とする。既存PRレビューを実タスクに含める追加回答を受領済み。実装は既存計測CLIの拡張に限定する。EA/既存CI/既存tests/Codex設定、推論floor、confidence0.90、省略OFFを保つ。

1. PR17最終差分・既存ファイル/config hash・CIを再照合。初期ログを保全し、出力増加と全provider削減の決定論的分解を追加する。
2. 実タスク記録・集計を追加する。同じ依頼/PRの再レビューは独立sampleに数えない。架空fixture/過去ログだけの再集計は実タスク件数から除外する。usage、時間、再修正、context再取得、テスト失敗、false negative/critical監査の欠測をnullで保持する。
3. PR11/12をそれぞれ1件として両arm Sol xHighで実レビューする。Aは変更ファイル全文と関連仕様、Bはdiff・必要変更ソース/関連仕様/テスト証拠。必要context不足時は追加取得し、追加呼出のusage/時間も加算する。秘密・実取引ログを送らない。レビュー結果は承認/マージ/修正の権限にならない。
4. 承認済みの実タスクごとに記録し、30件の中間報告、50件を目標に週次で継続集計する。追加証拠がない日はモデル比較を再実行せず件数も増やさない。重要群はxHigh、JEVは不要なら呼ばず低リスクの意味判断だけshadowで記録する。
5. 回帰テストをRED→GREEN、既存全体gate、1回の独立Sol xHighレビュー、PRのCI確認。レビュー省略と品質認定は常にfalse。実タスクの品質維持削減率は十分な件数・監査が揃うまで未確定。

追加: tools/workflow_eval/analysis.py, real_tasks.py, tests/test_workflow_real_tasks.py、実測結果/使用法文書。変更: cli.py、必要なusage provenance、SHA256SUMS.txt。既存テストは編集しない。

Ruling: 新規EA改修の要件は未指定なので件数のために改修を作らない。PR11/12のみ開始し、その後は実際に発生する承認済み作業を収集する。現在件数が30未満ならそのまま報告する。
Ruling: 同じタスクのA/Bレビューは比較実験の追加負担であり、実開発総費用の削減とは区別する。元実装の再修正・過去見逃しは取得できなければnull。
Ruling: 定期集計による不要な呼出を抑えるため、記録はタスク単位、集計は週次とする。初回の不完全な比較は欠測を保全し、同じタスクの無条件再実行を行わない。
